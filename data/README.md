# data

The inputs of the models and of figure 1. Nothing here is a result. Every file holds aggregated statistics:
group means and shares, country-level indicators. None holds microdata. The files and how the paper uses them
are below; the sources' terms and citations are in the root `README.md` (Data availability). How the design θ and
the tax rate τ of each OECD country are measured, source by source, is part 4 of the technical documentation
(`docs/TechnicalDocumentation.pdf`).

The workbooks are read by pandas with their cached formula values. If you change one, edit it in Excel or as
literal values: a workbook saved through openpyxl loses those values, pandas reads NaN, and every steady state fails.
